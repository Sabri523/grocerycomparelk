A local web app for online grocery comparison!

I was making it for public use and then I read the terms and conditions. Guys make sure to read the terms and conditions - first - when you are scraping. 
(scraping herewith refers to the physical scraping action and not the digital one).

To run this:
1. copy repository
2. open cmd and "cd <directory>"
3. "python main.py"
4. "python -m http.server 8000"
5. then go to http://localhost:8000/ in a browser.

main.py takes like one hour to run so beware.
