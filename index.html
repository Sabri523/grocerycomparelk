How this works: this page loads comparison.json, produced by running scraper_glomark.py → scraper_cargills.py → match_products.py in order (see README.md). Re-run those three scripts periodically (e.g. via a scheduled task) and refresh this page to pick up new prices.

Note on matching: Cargills and Glomark don't share product IDs, so items are paired by name similarity. Mismatches are possible, especially for generic names or different pack sizes — the match % next to each item is a rough confidence signal, not a guarantee.
