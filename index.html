How this works: this page loads comparison.json, produced by running scraper_glomark.py, scraper_cargills.py, scraper_keells.py, and scraper_spar2u.py, then match_products.py (see README.md). Re-run those scripts periodically (e.g. via a scheduled task) and refresh this page to pick up new prices. Any one scraper's output file can be missing — that store just shows "N/A" everywhere instead of breaking the page.

How "cheapest" is decided: for each row, only the stores that actually have a price are compared. When every store present on that row also has a usable pack size, each price cell shows the normalized per-100g/100ml/piece price as the main number — that's what decides "Cheapest" and what the raw pack price + pack size (shown smaller, underneath) get compared on. Only when a per-unit price isn't available on every present store does the main number fall back to the raw pack price directly. The "you save" line compares the cheapest store present against the next-cheapest one and says which basis was used. A row needs at least 2 stores with a price before any comparison is shown at all.

Note on matching: Cargills, Glomark, Keells, and SPAR2U don't share product IDs, so items are paired by name similarity and, where available, pack size (shown next to each price, e.g. "500g"). Matching is done in passes, one per store — Cargills items are matched against every other store first, then any leftover Glomark items get a chance to pair with leftover Keells or SPAR2U items, and so on — so it's a good-effort pairing, not a guaranteed globally-optimal one. Mismatches are still possible, especially for generic names — the match % and pack size next to each item are there so you can double-check before trusting a comparison. A "⚠ size unverified" tag means the pack size couldn't be confirmed on every store present in that row.
